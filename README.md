# Söz — тренажёр азербайджанских слов

PWA-тренажёр, который сам читает конспект в Google Docs, вытаскивает из него пары
«слово — перевод» и каждый день предлагает повторение с вариантами ответа.

## Как обновляются слова

Просто дописывайте конспект в Google Docs. Приложение проверяет документ при запуске
(не чаще раза в 3 часа) и по кнопке «Обновить» на главной. Новые слова идут в тренировку
первыми, прогресс по старым сохраняется.

Чтобы слово точно распозналось, пишите его на отдельной строке через тире:

```
tələsmək - спешить
qonşu – neighbor (O, mənim qonşumdur)
по-русски - RUSÇA
yatmaq - спать          bağlamaq - закрывать
```

Также понимаются пары в скобках `(bədən - тело, hissə - часть)` и таблицы из двух строк
(русские слова над азербайджанскими, колонки разделены пробелами).

Документ должен быть открыт по ссылке («Все, у кого есть ссылка → Читатель»).

### Рукописный конспект (PDF)

Второй источник — «Az lessons.pdf» с Google Drive. Это рукописные страницы без текста,
поэтому их распознали один раз (с исправлением орфографии) и сохранили в
`data/konspekt-pdf.txt` в том же формате «слово - перевод». Когда в PDF появятся новые
страницы, их нужно распознать заново и дописать в этот файл. Слова из PDF можно
отключить в настройках.

### Неверный перевод

После ответа нажмите «Неверный перевод?» (или нажмите на слово в разделе «Слова»).
Приложение найдёт это слово во всех источниках, покажет найденные переводы и строки,
где оно встречается. Выберите вариант или впишите свой — исправление сохранится
и переживёт обновления документа. Там же карточку можно скрыть.

## Как устроена тренировка

- Интервальное повторение по Лейтнеру: 1 → 2 → 4 → 7 → 14 → 30 → 60 → 120 дней.
  Ошибка возвращает слово на начальный уровень и повторяет его в той же сессии.
- Новые слова спрашиваются с азербайджанского, выученные — чаще с русского.
- После ответа показывается пример употребления с переводом и выделенным словом.
  Примеры лежат в `data/examples.json`: где возможно — ваше же предложение из конспекта
  (проверено, что слово там в нужном значении), иначе — простой пример, написанный заново.
  Для слов, которые появятся в документе позже, пример ищется среди вычитанных предложений.
- Неправильные варианты подбираются по уровню слова: для новых — та же часть речи,
  для выученных — похожие по написанию и окончанию (bağlamaq / başlamaq / ağlamaq).
- Цель на день и серия дней подряд, резервная копия прогресса в настройках.

## Предложения (грамматика)

Русское предложение нужно собрать по-азербайджански из плиток. Кроме нужных слов
даются лишние: другие лица и времена того же глагола (gəlirəm / gəlirsən / gəlmirəm),
другие падежи (evdə / evdən / evə), формы местоимений (mənə / sənə / məni)
и однокоренные слова из конспекта.

Сложность выбирается на главной (и в настройках):

| | Лёгкий | Средний | Сложный |
|---|---|---|---|
| Новые предложения | 3–6 слов | до 9 слов | 5–12 слов |
| Лишних слов | 2–3, непохожие | ~60% от длины, больше половины похожие | столько же, сколько нужных (5–8), все похожие |
| Подсказка | видно число слов | — | — |
| Порядок слов | небольшая перестановка засчитывается | небольшая перестановка засчитывается | только точный |

Предложения берутся из пар «русское — азербайджанское» в документе. Найденные на момент
публикации ~660 пар вычитаны: ошибки исправлены, неподходящие убраны
(`data/sentences-fixes.json`). Новые предложения из документа подхватываются
автоматически, но без вычитки — в ответе у них пометка «не проверено».

Прогресс хранится только в браузере на устройстве. Для переноса на другое устройство —
«Настройки → Резервная копия → Скачать / Восстановить».

## Как опубликовать (бесплатно)

PWA нужен адрес с HTTPS. Самый простой вариант — GitHub Pages:

1. Зарегистрируйтесь на github.com и создайте новый публичный репозиторий, например `soz`.
2. «Add file → Upload files» и перетащите **содержимое** этой папки
   (index.html, app.js, parser.js, styles.css, sw.js, manifest.webmanifest и папку icons).
   Нажмите «Commit changes».
3. «Settings → Pages → Build and deployment»: Source — «Deploy from a branch»,
   Branch — `main`, папка `/ (root)`, «Save».
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/soz/`.

Альтернатива без GitHub: app.netlify.com/drop — перетащите папку целиком.

## Установка на телефон

- **iPhone (Safari):** откройте адрес → «Поделиться» → «На экран Домой».
- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение».

После установки приложение открывается без интернета (слова берутся из последней
загруженной версии документа).

## Если поменяете код

Увеличьте `VERSION` в `sw.js` (например, `soz-v4`), иначе установленное приложение
продолжит показывать старую версию из кэша. После выкладки в приложении появится кнопка
«Вышла новая версия — обновить».
