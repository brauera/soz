# Söz — тренажёр азербайджанских слов

PWA-тренажёр, который сам читает конспект в Google Docs, вытаскивает из него пары
«слово — перевод» и каждый день предлагает повторение с вариантами ответа.

## Как обновляются слова

Просто дописывайте конспект в Google Docs. Приложение проверяет документ при запуске
(не чаще раза в 3 часа) и по кнопке «Обновить» на главной. Новые слова идут в тренировку
первыми, прогресс по старым сохраняется.

Чтобы слово точно распозналось, пишите его на отдельной строке через тире:

```
tələsmək - спешить
qonşu – neighbor (O, mənim qonşumdur)
по-русски - RUSÇA
yatmaq - спать          bağlamaq - закрывать
```

Также понимаются пары в скобках `(bədən - тело, hissə - часть)` и таблицы из двух строк
(русские слова над азербайджанскими, колонки разделены пробелами).

Документ должен быть открыт по ссылке («Все, у кого есть ссылка → Читатель»).

### Рукописный конспект (PDF)

Второй источник — «Az lessons.pdf» с Google Drive. Это рукописные страницы без текста,
поэтому их распознали один раз (с исправлением орфографии) и сохранили в
`data/konspekt-pdf.txt` в том же формате «слово - перевод». Когда в PDF появятся новые
страницы, их нужно распознать заново и дописать в этот файл. Слова из PDF можно
отключить в настройках.

### Неверный перевод

После ответа нажмите «Неверный перевод?» (или нажмите на слово в разделе «Слова»).
Приложение найдёт это слово во всех источниках, покажет найденные переводы и строки,
где оно встречается. Выберите вариант или впишите свой — исправление сохранится
и переживёт обновления документа. Там же карточку можно скрыть.

## Как устроена тренировка

Одна «Тренировка дня» без настроек сложности: до 20 слов (повторения по сроку и новые),
примерно каждый четвёртый шаг — сборка фразы, а между ними фразы из разговорника и задания
на окончания.

- Интервальное повторение по Лейтнеру: 1 → 2 → 4 → 7 → 14 → 30 → 60 → 120 дней.
  Ошибка возвращает слово на начальный уровень и повторяет его в той же тренировке.
- Слова спрашиваются в обе стороны: новое слово и повтор после ошибки — с азербайджанского
  на русский, остальные — поровну AZ → RU и RU → AZ.
- Неправильные варианты — той же части речи и похожей длины; похожие по написанию
  появляются только у хорошо выученных слов.
- После ответа показывается пример употребления с переводом и выделенным словом.
  Примеры лежат в `data/examples.json`: где возможно — ваше же предложение из конспекта
  (проверено, что слово там в нужном значении), иначе — простой пример, написанный заново.
- Цель на день и серия дней подряд, резервная копия прогресса в настройках.

### Сборка фразы

Фраза — это пример к одному из слов этой же тренировки (3–8 слов), появляется через пару
шагов после самого слова. Режим простой: 2–3 лишних непохожих слова, пустые ячейки
показывают, сколько слов во фразе, небольшая перестановка (глагол в конце) засчитывается.

Плитки можно нажимать и перетаскивать, как в Duolingo: нажатие добавляет слово в конец
или убирает его, перетаскиванием слово ставится в нужное место ответа, переставляется
внутри ответа или утаскивается обратно. Если во фразе ошибка — «Ошибка во фразе?», и её
больше не будет.

### Окончания

В каждую тренировку дня входят 3 задания с выбором из четырёх форм:

- существительные: «ev + где?» → evdə (среди вариантов evda, evdən, evə) — где, куда,
  откуда, много, мой, а после блока «Кого? Чей?» — ещё kitabı и kitabın;
- глаголы: «mən … (сейчас)» → gəlirəm, «sən … (вчера)» → gəldin.

Неправильные варианты — нарушенная гармония гласных, другой падеж, другое лицо или время.
После ответа — правило в одну строку и табличка всех форм слова. Чаще попадаются те виды
заданий, в которых больше ошибок. Слова — базовый набор (56 существительных, 38 глаголов),
формы проверены: `data/drill-words.json`, задания строит `drills.js`.

### Разговорник: магазин, такси, курьер

75 фраз в `data/phrases.json`, вычитанных под разговорный бакинский язык. Фразы двух видов:

- «Вы говорите» — сначала выбрать, как сказать по-азербайджански, когда фраза знакома —
  собрать её из плиток;
- «Вам говорят» (продавец, водитель, курьер) — понять: азербайджанская фраза → перевод.

В тренировку дня каждый день добавляются 3 новые фразы (вперемешку по темам, свои
и чужие) и повторения по сроку. Во вкладке «Фразы» видны все фразы темы и можно
позаниматься одной темой.

### Предложения из уроков

В разделе «Слова → Предложения» — ~580 пар «русское — азербайджанское» из конспекта,
вычитанных (`data/sentences-fixes.json`) и размеченных по уровню и грамматической теме
(`data/sentences-meta.json`). Они служат справочником и источником примеров к словам.

Прогресс хранится только в браузере на устройстве. Для переноса на другое устройство —
«Настройки → Резервная копия → Скачать / Восстановить».

## Уроки: курс по блокам

Раздел «Уроки» — курс из 39 блоков, как в Duolingo: блок со словами по теме чередуется
с блоком грамматики. Порядок взят из начальных учебников азербайджанского: буквы и звуки →
«я — врач» → гармония гласных → принадлежность → падежи → настоящее время → отрицание →
прошедшее и будущее → просьбы, «хочу / нужно / могу» → сложные формы. Блоки открыты все
сразу, на главной показан следующий по курсу.

**Смысловой блок** (люди и семья, еда, город и транспорт, покупки, время…) — урок из
5 новых слов:

1. карточка «Новые слова» с примерами;
2. каждое слово с азербайджанского на русский;
3. «Найдите пары»;
4. каждое слово с русского на азербайджанский;
5. сборка двух фраз-примеров, а в блоках про город, дом и покупки — ещё фразы из
   разговорника (такси, курьер, магазин).

Слова — из конспекта, разложенные по 16 темам (`data/word-topics.json`), плюс базовый
словарь начального уровня (`data/base.json`, ~430 слов): числа, дни недели, месяцы, семья,
еда, цвета, частые глаголы — то, чего в конспекте нет, потому что он начат не с первого
урока. Базовые слова появляются только в уроках, а после знакомства повторяются
в тренировке дня. Отключаются в настройках. Слова, добавленные в конспект позже, попадают
в блок «Новое из конспекта».

**Грамматический блок** — шпаргалка (правило и примеры, всегда доступна на странице блока)
и урок из заданий по одной теме:

- окончания только этой темы (например, в блоке «Где? Куда? Откуда?» — evdə, evə, evdən);
- «Вставьте слово»: предложение из конспекта с пропуском на месте нужной формы
  и четырьмя вариантами;
- сборка предложений из конспекта, подходящих теме по разметке или по форме.

**Блок «Magic table»** — отдельная тема по таблице из конспекта: после `Gəl` (давай), `Qoy`
(пусть, позволь), `Gərək` (следует), `Olar` (можно) и `… ki,` (чтобы) глагол получает одно и
то же окончание по лицу: gedim, gedəsən, getsin, gedək, gedəsiniz, getsinlər. В уроке:

- вопросы «с какого слова начинается „Давай…“» и «какое окончание у biz»;
- окончания с началом фразы: «Qoy o … (gəlmək)» → gəlsin;
- «Вставьте слово» в предложениях из конспекта — пропущено либо слово-сигнал, либо глагол;
- сборка этих предложений.

В блоке «Буквы и звуки» — вопросы о чтении букв, в блоке «Числа» — числа словами и цифрами
(47 ↔ qırx yeddi). Описание блоков, шпаргалки и правила отбора предложений — в `units.js`.

Уроки не расходуют дневной лимит новых слов: тренировка дня по-прежнему берёт свежие слова
из конспекта.

## Как опубликовать (бесплатно)

PWA нужен адрес с HTTPS. Самый простой вариант — GitHub Pages:

1. Зарегистрируйтесь на github.com и создайте новый публичный репозиторий, например `soz`.
2. «Add file → Upload files» и перетащите **содержимое** этой папки
   (index.html, app.js, parser.js, styles.css, sw.js, manifest.webmanifest и папку icons).
   Нажмите «Commit changes».
3. «Settings → Pages → Build and deployment»: Source — «Deploy from a branch»,
   Branch — `main`, папка `/ (root)`, «Save».
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/soz/`.

Альтернатива без GitHub: app.netlify.com/drop — перетащите папку целиком.

## Установка на телефон

- **iPhone (Safari):** откройте адрес → «Поделиться» → «На экран Домой».
- **Android (Chrome):** откройте адрес → меню ⋮ → «Установить приложение».

После установки приложение открывается без интернета (слова берутся из последней
загруженной версии документа).

## Если поменяете код

Увеличьте `VERSION` в `sw.js` (например, `soz-v11`), иначе установленное приложение
продолжит показывать старую версию из кэша. После выкладки в приложении появится кнопка
«Вышла новая версия — обновить».
